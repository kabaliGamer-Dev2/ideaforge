VERDICT — PLAN B (2.0) WINS: 86 vs 48

Both plans can ship. The difference is what the demo survives. Plan A's entire demo hangs on one third-party provider staying healthy for five minutes; Plan B treats that provider as optional by design.

  • B — Dual-path fallback: the single biggest ratio swing. Unplug the AI and the product still works — which is also the most impressive demo moment a panel can see.
  • B — Deploy-first (T+15): the one failure mode you can't debug quickly is caught in the first 20 minutes.
  • B — Verified logic (T+60): sanitisation and ranking bugs are found by assertions, not by the audience.
  • B — Checkpoint E at T+110: a complete product at a public URL with no AI in it. Everything after is upside.
  • A — Streaming wow: real, but it is a garnish. A non-streaming demo that works beats a streaming demo that dies.

Plan A wins only on scaffolding speed and streaming feel — neither survives contact with a dead API key.

BEST MOVE — run Plan B, steal Plan A's garnish

Execute Plan B exactly as written (docs update 2-o plan/00–05). If Checkpoint G (T+155) passes with time to spare, spend the last minutes on the one Plan A feature worth borrowing: streaming the mentor reply through the Vercel AI SDK on the LLM path only, keeping the fallback static. Streaming is an enhancement on top of a safe core — never the core itself.
