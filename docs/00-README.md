# Docs Index — IdeaForge: AI Project Idea Generator & Mentor

Hackathon: **3 hours**. This index tells you what to feed your AI coding agent, and in what order.

## How to use these docs

Feed these files to your AI coding agent **in this order**:

| # | File | Purpose | When |
|---|------|---------|------|
| 1 | `01-PRD.md` | What to build (scope locked for 3 hours) | Read this FIRST |
| 2 | `03-GITHUB-REFERENCES.md` | Fork this repo first — don't build from scratch | Before any code |
| 3 | `04-ARCHITECTURE.md` | Data model, routes, prompt templates | During build |
| 4 | `05-SPRINT-PLAN.md` | Hour-by-hour tasks + copy-paste agent prompts | During build |
| 5 | `02-RESEARCH.md` | Only needed for the pitch / judge Q&A | Optional |
| 6 | `06-PITCH.md` | Demo script for judges | Before demo |

## Golden rule for the 3-hour build

> **fork → strip → repurpose → ship.**

Do NOT start a fresh `create-next-app`. Start from the reference repo in file `03-GITHUB-REFERENCES.md` — it saves ~1.5 hours of scaffolding.
