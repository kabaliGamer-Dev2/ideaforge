## Phase 3: Idea Generator (Hour 1–1.5)

### 📄 Page 3.1 — `/api/generate-ideas` Route

- [ ] `POST /api/generate-ideas` route handler
- [ ] Validate request body against `UserProfile` type
- [ ] Build prompt from Idea Generator template (04-ARCHITECTURE.md)
- [ ] Call LLM with strict JSON response format
- [ ] Parse + validate `ProjectIdea[]` shape

- [ ] Timeout handling (30s)
- [ ] Error responses: 400 invalid body / 500 provider error + message
