# Hackathon Pitch — IdeaForge

## Elevator Pitch (30 sec)

> "Every final-year student wastes weeks picking a project, then gets stuck
> mid-way because no one told them it wasn't feasible. IdeaForge is an AI
> mentor: tell it your skills and time, it gives you a feasible idea AND a
> week-by-week plan to actually finish it — like a professor in your pocket."

## Demo Script (under 5 min)

1. **(30s)** Show the problem: generic "100 project ideas" blog — outdated, generic.
2. **(30s)** Enter skills: "React, Python, basic ML", 8 weeks, intermediate.
3. **(45s)** Show 4 generated ideas with novelty scores — pick one.
4. **(2 min)** Show streamed Mentor Plan: MVP features, tech stack justification, week-by-week roadmap, viva questions.
5. **(30s)** Click "Download as Markdown" — show exported plan.
6. **(30s)** Close: "This isn't a list. It's a mentor."

## Judge FAQ

- **"Isn't this just ChatGPT?"**
  → Structured, role-specific, multi-step prompt chain producing a feasibility-checked roadmap, not a single freeform answer. Repeatable, consistent output format.

- **"How does it scale?"**
  → Stateless API routes; swap in a queue + DB for persistence; add fine-tuning on real project outcome data later.

- **"What's next?"**
  → GitHub repo starter generation per idea; integration with university project databases to avoid duplicate topics.

## Differentiator to repeat 3x during demo

> "Personalized feasibility + week-by-week mentorship — not another idea list."
