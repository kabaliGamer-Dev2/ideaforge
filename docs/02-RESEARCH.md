# Research Summary — IdeaForge

## 1. Existing Solutions & Gaps

| Solution | What it does | Gap |
|---|---|---|
| Static "100 project ideas" blogs | List generic ideas | No personalization, outdated, no roadmap |
| Plain ChatGPT prompt | Ask for ideas manually | No structure, no memory of skill level, one-shot, no roadmap discipline |
| Devpost / Kaggle idea boards | Community project listings | Not tailored, not mentoring |
| University project guidance (human mentors) | Personalized | Doesn't scale, slow, availability limited |

## 2. Insight

The unmet need isn't *"give me an idea"* — it's **"tell me if I can actually finish it, and how."**

Judges respond well to tools that reduce real anxiety (will I finish this project in one semester?) rather than novelty-only demos.

## 3. Positioning

> "ChatGPT gives you an idea. IdeaForge gives you a professor."

## 4. Why this wins the demo

1. **Personalization is visible**: output references the student's actual skills/weeks.
2. **Feasibility check**: every idea is constrained to `weeksAvailable` and ONE student.
3. **Mentorship beyond selection**: roadmap + viva prep = judges' favorite part.
4. **Streaming UI**: live, chat-like feel — feels like a real mentor, not a form.
